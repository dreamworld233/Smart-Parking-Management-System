# Smart Parking Management System

智慧停车管理系统（基于车牌识别技术）。

## 简介

解决车辆进出、安全、收费、引导等问题。用户通过手机端实现车位预约、车辆引导、自动扣费，提高停车效率和车位利用率。

## 功能模块

- **网页端**：登录、系统信息管理、车位信息管理、IC 卡信息管理、固定/临时车辆管理、收费管理、车牌识别、打印管理。
- **移动端**：注册登录、信息修改、车位查询、车辆引导、消费记录、会员办理、车位预约、计费扣款。
