# 智慧停车场管理系统 —— 开发计划（V3 定稿）

> 周期：4 周。更新时间：2026-09-08。
> 配套：《移动端需求.md》《智慧停车场管理系统-项目需求分析与设计方案.docx》

## 1. 目标与边界

打通「识别 → 预约 → 停车 → 计费 → 缴费 → 离场 → 管控」闭环，交付可演示、可验收的完整系统：

- **移动端**（Android 原生 Java）：账号资料、车位查询、预约、引导、记录、实时计费、会员、模拟支付。
- **网页端**（Spring Boot + Thymeleaf）：管理员登录 + 关键管理 CRUD。
- **后端**（Spring Boot 3 + MyBatis-Plus + MySQL）：两端共享领域 API + JWT 鉴权。
- **车牌识别**：后端 **mock 实现**（上传 → 返回识别结果），不做独立 Python 服务、不接真实摄像头。文档中写为「预留硬件/算法接口」。

已裁剪（保留文档描述，降级实现）：IC 卡 = 简单 CRUD；权限 = 管理员/维护两级；移动端只做 Android；无真实支付（Mock + 抽象接口层）。

## 3. 技术栈

- 后端：Spring Boot 3.5.7 / MyBatis-Plus 3.5.10 / MySQL 8 / jjwt 0.12.6（已跑通注册登录 + JWT）
- 移动端：Android 原生 Java，Retrofit 2.11 + Gson（已接真后端，baseUrl `10.0.2.2:8080`）
- 网页端：Thymeleaf（管理员后台）
- 车牌识别：后端 mock 接口（预留换真实算法）

## 4. 分阶段计划（4 周主线）

### W1 —— 地基 + 账号资料闭环
- 后端：全套表 schema（含 user/car/wallet/space/reservation/record/member/payment 等）、JWT 鉴权拦截器、用户资料查询/修改、车辆绑定/解绑、停车场/车位种子数据
- 移动端：底部导航框架、个人中心（资料/改密码）、车辆管理页
- ✅ 里程碑：注册登录 → 资料/车辆管理全通

### W2 —— 车位预约核心闭环
- 后端：预约创建/取消/超时释放、车位三色状态接口
- 移动端：车位查询页（三色 + 5s 轮询）、预约流程、我的预约、静态指引图 + 目标位高亮
- ✅ 里程碑：查位 → 预约 → 引导 全通

### W3 —— 计费支付闭环
- 后端：停车记录、计费规则（单价/单位/封顶 + 会员折扣）、钱包、`PaymentGateway` 抽象 + Mock、会员开通、车牌进出场模拟
- 移动端：消费记录、实时计费展示、会员办理、支付签约 + 扣款
- ✅ 里程碑：进场 → 计费 → 扣款 → 出场 全链

### W4 —— 网页端 + 集成收尾
- 网页端（Thymeleaf）：管理员登录、用户/车位管理、固定/临时停车查询、收费规则、识别异常处置、IC 卡简单 CRUD
- 收尾：演示种子数据、前后端联调走查、文档齐套、演示视频
- ✅ 里程碑：全套可演示
