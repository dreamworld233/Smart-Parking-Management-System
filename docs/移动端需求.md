# 移动端需求文档

> 智慧停车管理系统 —— 移动端（Android 原生，Java）

## 1. 场景定义（假想）

- 一个小区，分 **南区** 与 **北区**，各设一个停车场。
- 服务对象：小区住户（用户）。
- 用户可在手机上完成：注册登录、车位查询、车位预约、车辆引导（指引图）、会员办理、自动计费扣款。

## 2. 技术栈

| 层 | 选型 |
|---|---|
| 移动端 | Android 原生（Java） |
| 后端 | Spring Boot 3 (Java 17) + MyBatis-Plus + MySQL |
| 车牌识别 | Python 微服务（FastAPI + HyperLPR） |
| 支付 | 模拟支付（抽象接口层，可换支付宝沙箱） |

## 3. 模块明细

### 3.1 登录板块

- **凭证**：手机号 + 密码。无用户名字段。
- **注册**：新手机号 → 注册（补密码，车牌号可选）。
- **登录**：手机号 + 密码 → 签发 token。
- **退出**：清本地 token，回登录页。
- **校验**：手机号唯一、非空；密码非空。

### 3.2 信息修改

- 改昵称、头像、手机号、密码。
- **车辆管理**：绑定 / 解绑车辆（一个用户可有多辆车，`1:N`）。
- 改手机号 / 车牌号需同步校验唯一性。

### 3.3 车位查询

- 查看南 / 北区停车场车位状态。
- **三色状态**：

| 颜色 | 状态 |
|---|---|
| 🟢 绿 | 空闲 |
| 🟡 黄 | 被预约 |
| 🔴 红 | 已有车 / 维修 |

- 实时刷新：轮询 5s。

### 3.4 车辆引导（指引图）

- 不做实时地图导航，改 **静态指引图**。
- 小区平面图，标注南 / 北区停车场、分区、车位编号。
- 用户预约后，显示指引图并高亮目标车位。

### 3.5 消费记录

- 查询历史停车记录：车牌号、入场时间、出场时间、时长、费用、支付状态。
- 按时间筛选。

### 3.6 会员办理

- 开通月卡 / 年卡。
- 字段：会员类型（月/年）、起止时间、车牌号、支付状态。
- 权益：固定车位、费用优惠（计费模块按会员打折）。

### 3.7 车位预约

- 查空车位 → 预约 → 预留 / 取消 / 超时解锁。
- 状态流转：

```
空闲 → 已预约（用户预约，预留）
     → 已使用（入场核销）
     → 已超时（超时未入场，自动解锁回空闲）
     → 已取消（用户取消，回空闲）
```

- 超时解锁：预约记录截止时间，后台定时任务 / 查询时判断超时 → 释放车位。

### 3.8 计费板块（快捷支付）

- 车牌识别进出场 → 自动计费 → 绑定微信/支付宝 → 免密扣款 → 出场。
- **实时计费**：停车中前端实时刷新费用。

## 4. 快捷支付方案

真实「免密代扣」需企业资质，学校项目不可行。采用 **模拟支付 + 抽象接口层**。

### 流程

```
签约：用户绑定微信/支付宝 → 存签约记录（同意"免密代扣协议"）
免密额度：≤ 阈值(如100元)自动扣；超阈值要求确认（模拟输密码/短信验证码）
扣款：出场识别车牌 → 算费 → 查签约 → 校验额度
      → 扣钱包余额 → 生成流水 → 抬杆放行
```

### 抽象接口层

```java
public interface PaymentGateway {
    PayResult pay(String carNo, BigDecimal amount);
    void refund(String orderId);
}
```

- 现在：`MockPaymentGateway`（扣本地钱包余额）。
- 以后/加分项：`AlipaySandboxGateway`（支付宝沙箱，个人可申请）。
- 换真实支付只改实现类，不动业务代码。

## 5. 数据实体

```
用户 User：id、手机号、密码、昵称、头像、会员类型
车辆 Car：id、user_id、车牌号
钱包 Wallet：user_id、balance
车位 Space：id、停车场(南/北)、编号、状态、类型(固定/临时)
预约 Reservation：id、user_id、space_id、预约时间、截止时间、状态
停车记录 Record：id、car_id、space_id、入场、出场、时长、费用、支付状态
签约 BindPay：user_id、type(微信/支付宝)、status、免密额度
支付流水 Payment：record_id、amount、type、status、时间
```

## 6. API 接口清单（移动端 ↔ 后端）

### 认证
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/register | 注册（手机号+密码+车牌可选） |
| POST | /api/auth/login | 登录，返回 token |
| POST | /api/auth/logout | 退出 |

### 用户 / 车辆
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/user/info | 查询个人信息 |
| PUT | /api/user/info | 修改个人信息 |
| GET | /api/user/vehicles | 车辆列表 |
| POST | /api/user/vehicles | 绑定车辆 |
| DELETE | /api/user/vehicles/{id} | 解绑车辆 |

### 车位 / 预约
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/parking/areas | 停车场列表（南/北） |
| GET | /api/parking/spaces | 车位列表（含三色状态） |
| POST | /api/reservation | 预约车位 |
| GET | /api/reservation/list | 我的预约 |
| DELETE | /api/reservation/{id} | 取消预约 |

### 停车记录 / 计费
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/record/list | 停车记录列表 |
| GET | /api/record/{id} | 记录详情 |
| GET | /api/payment/rule | 计费规则 |

### 支付 / 会员
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/payment/bind | 绑定支付方式（签约） |
| GET | /api/wallet/balance | 钱包余额 |
| POST | /api/payment/pay | 发起扣款（模拟） |
| POST | /api/member/apply | 开通会员 |
| GET | /api/member/info | 会员信息 |

## 7. 开发顺序

1. 登录 / 注册（手机号，无用户名）
2. 车位查询（三色状态 + 南 / 北区）
3. 车位预约（状态流转 + 指引图）
4. 计费展示 + 停车记录
5. 模拟支付闭环（签约 → 自动扣款 → 流水）
6. 会员办理（月 / 年卡）
7. 信息修改 + 车辆绑定 + 消费记录

## 8. 跨模块公共点

| 点 | 说明 |
|---|---|
| 实时性 | 车位状态、计费金额、预约超时 → 轮询 5s |
| 唯一性 | 手机号、车牌号 → 后端唯一索引 |
| 非空 | 表单必填项后端校验 |
| 会话 | 登录后 JWT token，接口带 token 鉴权 |
| 车牌关联 | 车牌号是核心外键，串起 用户↔车辆↔进出场↔计费↔预约 |
